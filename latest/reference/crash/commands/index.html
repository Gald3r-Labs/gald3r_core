    Tasks¶

    Creating, updating, and tracking work in .gald3r/tasks/.

    • /g-backlog-curate -- Walk the live backlog against shipped code and propose dispositions (never auto-cancels).
    • /g-go -- Two-phase pipeline: implement tasks/bugs, then auto-spawn a fresh independent reviewer (optional swarm mode).
    • /g-go-code -- Implement queued tasks/bugs through to awaiting-verification only; never runs review itself
    • /g-go-code-swarm -- Alias for g-go-code --swarm: implementation-only swarm that partitions tasks into parallel coding buckets
    • /g-go-go -- Autopilot loop: parallel implement then review until a hard stop (default swarm; --no-code-swarm is sequential)
    • /g-go-review -- Verify tasks/bugs awaiting review in a fresh session: PASS/FAIL scoring, no self-review, auto-commits verdict.
    • /g-go-review-swarm -- Run g-go-review verification in parallel across M reviewer agents on the review queue (round-robin).
    • /g-go-swarm -- Run the full g-go pipeline (implement then auto-review) in swarm mode across parallel Phase 1/2 agents.
    • /g-grooming -- Deprecated stub
    • /g-juggernaut -- Alias for g-mission
    • /g-kamikaze -- Alias for g-mission
    • /g-mission -- Run an autonomous g-go-go loop until a stated condition is met, optionally draining the queue.
    • /g-propose -- Generate a proposal doc (design, PRD draft, task breakdown) from a feature description
    • /g-pt -- List, switch, copy, or validate gald3r workflow profiles (project types) via gald3r project-type
    • /g-queue -- Append a follow-up prompt to a running g-go-code worktree's queue.md, or list pending items
    • /g-report -- Generate a backlog status report: last commit, available/in-progress/blocked tasks, recommendations
    • /g-sesh-goal-add -- Record a session goal for the CURRENT session only, via gald3r sesh-goal add
    • /g-sesh-goal-rem -- Remove a session goal by its list number or matching text, via gald3r sesh-goal rem.
    • /g-steer -- Inject a one-shot steering prompt into a running g-go-code worktree session via steer.md.
    • /g-task-add -- Create a new task (ID, complexity score, file, TASKS.md entry) via g-skl-tasks CREATE TASK.
    • /g-task-archive -- Archive completed/failed/cancelled tasks into .gald3r/archive/ buckets via gald3r task archive.
    • /g-task-del -- Hard-delete a mis-routed task via git rm + commit, per g-rl-33 Routing Error Hard Delete (gald3r task delete).
    • /g-task-new -- Deprecated alias for @g-task-add
    • /g-task-sync-check -- Validate TASKS.md matches the tasks/ files, catching phantom or orphaned task entries.
    • /g-task-upd -- Update a task's status, priority, dependencies, promotion/demotion, or release-hold fields.
    • /g-task-update -- Deprecated alias for @g-task-upd
    • /g-wishlist-mine -- Mine a human-prose wishlist doc into gald3r tasks via g-skl-wishlist-mine, read-only against the doc
